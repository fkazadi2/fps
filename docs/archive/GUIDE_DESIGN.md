# 📘 Guide du Nouveau Design - Page d'Accueil FPS

## Introduction

Ce guide détaille les changements visuels et techniques apportés à la page d'accueil du site FPS. Le nouveau design maintient l'identité institutionnelle tout en apportant une touche moderne et créative.

---

## 🔧 Techniques CSS Avancées

### 1. Glassmorphisme:
```css
background: rgba(255, 255, 255, 0.1);
backdrop-filter: blur(10px);
border: 1px solid rgba(255, 255, 255, 0.2);
```

### 2. Effet de halo sur icônes:
```css
/* Élément blur en arrière-plan */
.absolute.inset-0.bg-primary.opacity-20.blur-lg

/* Icône principale au-dessus */
.relative.w-16.h-16.bg-gradient...
```

### 3. Ligne décorative animée:
```css
.absolute.bottom-0.h-1
.bg-gradient-to-r.from-transparent.via-color.to-transparent
.transform.scale-x-0
.group-hover:scale-x-100
.transition-transform.duration-500
```

### 4. Animations de compteur:
```javascript
// Fonction d'easing pour ralentir vers la fin
const easeOutQuad = (t) => t * (2 - t);

// Animation progressive sur 2 secondes
setInterval(() => {
  const progress = easeOutQuad(frame / totalFrames);
  setCount(targetValue * progress);
}, 1000 / 60);
```

## ⚡ Performance

### Optimisations appliquées:

✅ **Animations GPU**:
- Utilisation de `transform` et `opacity`
- Évitement de `width`, `height`, `top`, `left`

✅ **Lazy Loading**:
- Images Next.js avec priorité
- Intersection Observer pour animations

✅ **Transitions efficaces**:
- Durées optimales (300-500ms)
- Cubic-bezier pour fluidité

✅ **CSS moderne**:
- Variables CSS pour cohérence
- Tailwind JIT pour taille minimale

## ♿ Accessibilité

### Conformité WCAG 2.1 AA:

✅ **Contraste**: Minimum 4.5:1 pour texte normal
✅ **Navigation clavier**: Tous les éléments interactifs
✅ **Aria-labels**: Sur tous les boutons et liens
✅ **Focus visible**: Outline sur tous les éléments focusables
✅ **Animations**: Respecte `prefers-reduced-motion`

### Exemples:
```jsx
// Bouton avec aria-label
<button aria-label="Aller au slide 1">

// Respect des préférences utilisateur
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 🚀 Comment Personnaliser

### 1. Modifier les couleurs:

Dans `src/app/globals.css`:
```css
:root {
  --primary: #005bb0;    /* Votre bleu */
  --secondary: #29335C;  /* Votre violet */
  --accent: #F8C03E;     /* Votre jaune */
  --danger: #e10000;     /* Votre rouge */
}
```

### 2. Modifier le contenu:

Dans `src/app/page.tsx`:
```javascript
const defaultHomepageContent = {
  mission: {
    title: "Votre titre",
    subtitle: "Votre sous-titre"
  },
  features: [
    {
      title: "Votre feature",
      description: "Votre description",
      link: "/votre-lien",
      icon: "education" // ou "prevention", "collaboration"
    }
  ]
}
```

### 3. Ajouter une valeur:

Dans `src/app/page.tsx`, section Valeurs:
```jsx
{
  icon: <VotreIcone />,
  title: "Votre valeur",
  description: "Description",
  color: "from-color-500 to-color-600"
}
```

### 4. Modifier les animations:

Dans `src/app/globals.css`:
```css
@keyframes votre-animation {
  from { /* état initial */ }
  to { /* état final */ }
}

.animate-votre-animation {
  animation: votre-animation 1s ease-in-out;
}
```

## 🐛 Dépannage

### Problème: Animations ne fonctionnent pas

**Solution**:
- Vérifier que `AnimatedSection` est bien importé
- Vérifier la prop `direction` ("up", "left", "right")
- Vérifier le `delay` (en ms)

### Problème: Compteurs ne s'animent pas

**Solution**:
- Vérifier l'import de `useState`, `useEffect`, `useRef`
- Vérifier que `isVisible` est bien défini
- Vérifier l'Intersection Observer

### Problème: Dégradés ne s'affichent pas

**Solution**:
- Vérifier la syntaxe Tailwind: `bg-gradient-to-br`
- Vérifier les couleurs: `from-blue-500 to-red-600`
- Vérifier que JIT est activé dans `tailwind.config.js`

### Problème: Glassmorphisme ne fonctionne pas

**Solution**:
- Vérifier `backdrop-filter: blur(10px)`
- Vérifier le support navigateur (pas IE11)
- Ajouter le préfixe `-webkit-` si nécessaire

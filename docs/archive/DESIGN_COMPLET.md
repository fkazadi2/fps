## 🎭 Animations et Effets

### Animations au Scroll
- `fadeInUp`: Apparition en fondu avec translation Y
- `opacity-0 → opacity-100`: Apparition progressive
- `translate-y-8 → translate-y-0`: Glissement vers le haut
- Délais progressifs: 100ms, 150ms, 200ms entre cartes

### Effets au Survol
| Élément | Transformation |
|---------|---------------|
| Cartes | `-translate-y-2` (levée 8px) |
| Icônes | `rotate-6` ou `rotate-12` |
| Images | `scale-110` (zoom 10%) |
| Lignes | `scale-x-0 → scale-x-100` (étirement) |
| Boutons | `scale-105` (agrandissement 5%) |
| Logos | `grayscale → grayscale-0` (couleur) |

### Animations Continues
- `animate-pulse`: Pulsation (2s)
- `animate-spin`: Rotation (20s pour lent)
- `animate-ping`: Onde expansive (1s)
- `animate-shimmer`: Brillance glissante (2s)

## 🎯 Éléments Communs

### Badges
Tous les badges utilisent le même style:
```jsx
<span className="px-4 py-2 bg-[color] bg-opacity-10 text-[color] rounded-full text-sm font-semibold tracking-wide uppercase">
  Texte
</span>
```

Variantes de couleurs:
- Rouge: Mission, Actualités
- Bleu: Carte, Stats
- Violet: Événements
- Jaune: Partenaires
- Blanc: CSU, CTA

### Titres
Structure standard:
```jsx
<h2 className="text-4xl md:text-5xl font-extrabold text-[var(--primary)] mb-4">
  Titre Principal
</h2>
<p className="text-xl text-gray-600 max-w-3xl mx-auto">
  Sous-titre explicatif
</p>
```

### Cartes
Structure de base:
```jsx
<div className="group bg-white rounded-2xl shadow-xl overflow-hidden border border-gray-100 hover:shadow-2xl hover:-translate-y-2 transition-all duration-500">
  {/* Contenu */}
</div>
```

### Boutons CTA
Deux styles principaux:

**Style 1 - Uni**:
```jsx
<button className="px-8 py-4 bg-white text-[var(--primary)] rounded-xl font-semibold hover:shadow-2xl transition-all transform hover:scale-105">
```

**Style 2 - Gradient**:
```jsx
<button className="px-8 py-4 bg-gradient-to-r from-[color1] to-[color2] text-white rounded-xl font-semibold hover:shadow-2xl transition-all transform hover:scale-105">
```

## 🛠️ Technologies Utilisées

### Framework & Libraries
- **Next.js 14+**: Framework React
- **Tailwind CSS**: Styling
- **Lucide React**: Icônes
- **Next/Image**: Optimisation images
- **React Hooks**: useState, useEffect, useRef
- **Intersection Observer**: Animations au scroll

### Techniques CSS
- **Glassmorphisme**: `backdrop-filter: blur(10px)`
- **Dégradés**: `bg-gradient-to-r`, `bg-gradient-to-br`
- **Transitions**: `transition-all duration-500`
- **Transformations**: `transform`, `scale`, `translate`, `rotate`
- **Animations**: `@keyframes` personnalisées
- **Grid**: `grid-cols-1 md:grid-cols-2 lg:grid-cols-4`
- **Flexbox**: `flex`, `items-center`, `justify-between`

## ⚡ Performance

### Optimisations Appliquées
✅ **Animations GPU**:
- Utilisation de `transform` et `opacity`
- Évitement de `width`, `height`, `top`, `left`

✅ **Images**:
- Next/Image avec lazy loading
- Sizes appropriés pour responsive
- Priority sur première image du slider

✅ **Intersection Observer**:
- Déclenchement animations au scroll
- Disconnect après apparition
- Threshold optimisé (0.1-0.2)

✅ **Transitions**:
- Durées optimales (300-500ms)
- Cubic-bezier pour fluidité
- Délais progressifs pour cascade

✅ **Contraste de couleurs**:

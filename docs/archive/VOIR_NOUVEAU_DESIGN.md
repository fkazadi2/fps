## 🎨 Personnalisation

### Modifier les Couleurs

Éditez `src/app/globals.css`:
```css
:root {
  --primary: #005bb0;    /* Bleu principal */
  --secondary: #29335C;  /* Bleu foncé */
  --accent: #F8C03E;     /* Doré */
  --danger: #e10000;     /* Rouge */
}
```

Sauvegardez, la page se rechargera automatiquement! 🔄

## 🐛 En cas de Problème

### Le serveur ne démarre pas?
```bash
npm install
npm run dev
```

### Les animations ne fonctionnent pas?
- Actualisez la page (Ctrl+R ou Cmd+R)
- Videz le cache (Ctrl+Shift+R ou Cmd+Shift+R)

### Les couleurs ne changent pas?
- Vérifiez que vous modifiez bien `globals.css`
- Sauvegardez le fichier
- Attendez le rechargement automatique

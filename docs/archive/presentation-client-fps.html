Plan de Déploiement VPS

🖥️
Spécifications VPS Recommandées
CPU : 4 vCPU minimum
RAM : 8 GB (16 GB recommandé)
SSD : 100 GB NVMe
OS : Ubuntu 22.04 LTS
Bande passante : 1 Gbps
Fournisseurs : OVH, Hetzner, AWS EC2
~30-60 €/mois
📋
Étapes de Déploiement
1. Provisionner le VPS + SSH sécurisé
2. Installer Node.js 20, PM2, Docker
3. Installer & configurer Nginx
4. SSL automatique Certbot (Let's Encrypt)
5. Clone repo + npm install + build
6. Variables d'environnement (.env.production)
7. MongoDB Docker ou Atlas cloud
Délai : 1-2 jours
🔧
Variables d'Environnement Production
MONGODB_URI=mongodb+srv://...
NEXTAUTH_SECRET=[clé-64-chars]
NEXTAUTH_URL=https://fps.gouv.cd
CLOUDINARY_CLOUD_NAME=...
NODE_ENV=production
📈
Monitoring & Maintenance
PM2 : Redémarrage automatique, logs
Nginx : Logs access + error
MongoDB : Backup quotidien mongodump
Uptime : UptimeRobot / Better Uptime
Updates : npm audit + patch mensuel
SLA > 99.5%

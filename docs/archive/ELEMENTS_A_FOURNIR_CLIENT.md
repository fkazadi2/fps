# 📋 ÉLÉMENTS À FOURNIR PAR LE CLIENT - FPS WEBSITE

**Date de création:** 23 Janvier 2026  
**Projet:** Améliorations Site Web FPS - Kasaï-Oriental

---

## 🎯 OBJECTIF
Cette liste recense tous les éléments (contenus, images, documents) que le client doit fournir pour finaliser l'implémentation des améliorations demandées.

---

## 📸 1. IMAGES & VISUELS

### 1.1 Photos réelles de projets de terrain
**Où utiliser:** Hero slider, Section Mission, Actualités, Galerie média  
**Quantité:** Minimum 10-15 photos haute résolution  
**Format:** JPG/PNG, minimum 1920x1080px  
**Contenu requis:**
- [ ] Photos de projets financés par le FPS en action
- [ ] Photos d'infrastructures sanitaires financées
- [ ] Photos de dotations en médicaments/équipements
- [ ] Photos de zones de santé bénéficiaires
- [ ] Photos de cérémonies de remise de dotations

### 1.2 Photos d'équipes FPS en action
**Où utiliser:** Section "Voix du terrain", Galerie média, Page Mission  
**Quantité:** Minimum 5-8 photos  
**Format:** JPG/PNG, minimum 1920x1080px  
**Contenu requis:**
- [ ] Équipes FPS lors de missions de terrain
- [ ] Équipes lors d'activités de sensibilisation
- [ ] Équipes lors de formations du personnel de santé
- [ ] Équipes lors de visites de zones de santé

### 1.3 Photos de bénéficiaires (avec autorisations)
**Où utiliser:** Section "Voix du terrain", Témoignages, Actualités  
**Quantité:** Minimum 5-10 photos  
**Format:** JPG/PNG, minimum 1920x1080px  
**Contenu requis:**
- [ ] Photos de bénéficiaires recevant des soins
- [ ] Photos de communautés bénéficiaires
- [ ] Photos lors d'activités de sensibilisation communautaire
- [ ] **IMPORTANT:** Autorisations écrites pour utilisation des images

### 1.4 Photos d'activités de sensibilisation
**Où utiliser:** Section "Voix du terrain", Galerie média  
**Quantité:** Minimum 8-10 photos  
**Format:** JPG/PNG, minimum 1920x1080px  
**Contenu requis:**
- [ ] Activités de sensibilisation dans les zones rurales
- [ ] Séances d'éducation sanitaire communautaire
- [ ] Campagnes de prévention
- [ ] Mobilisation communautaire

## 📝 2. CONTENUS TEXTUELS

### 2.1 Témoignages de bénéficiaires
**Où utiliser:** Section "Voix du terrain", Page Mission  
**Quantité:** Minimum 3-5 témoignages complets  
**Format:** Texte Word ou PDF  
**Contenu requis pour chaque témoignage:**
- [ ] Nom complet (ou prénom seulement si anonyme)
- [ ] Localisation (zone de santé, province)
- [ ] Témoignage complet (200-300 mots)
- [ ] Photo du bénéficiaire (avec autorisation)
- [ ] Date du témoignage

### 2.2 Exemples concrets de projets phares avec résultats chiffrés
**Où utiliser:** Page Mission (section Impact chiffré), Publications (Résultats tangibles)  
**Quantité:** Minimum 5-7 projets  
**Format:** Texte structuré avec chiffres  
**Contenu requis pour chaque projet:**
- [ ] Nom du projet
- [ ] Description du projet (100-150 mots)
- [ ] Résultats chiffrés (personnes touchées, montants, etc.)
- [ ] Impact mesurable (pourcentages d'amélioration, etc.)
- [ ] Date de réalisation
- [ ] Zone géographique concernée
- [ ] Photos du projet (optionnel mais recommandé)

### 2.3 Coordonnées exactes
**Où utiliser:** Page Contact, Header  
**Format:** Texte simple  
**Contenu requis:**
- [ ] **Adresse physique complète:** 
  - [ ] Rue/Avenue exacte
  - [ ] Numéro de bâtiment
  - [ ] Commune/Quartier
  - [ ] Ville (Mbuji-Mayi)
  - [ ] Province (Kasaï-Oriental)
  - [ ] Coordonnées GPS (latitude, longitude) pour la carte interactive

- [ ] **Téléphone:**
  - [ ] Numéro principal (format international: +243 XXX XXX XXX)
  - [ ] Numéro secondaire (si applicable)
  - [ ] Numéro WhatsApp (si disponible)

- [ ] **Email:**
  - [ ] Email principal (secretariat@fps.cd ou autre)
  - [ ] Email pour réclamations (si différent)
  - [ ] Email pour partenariats (si différent)

- [ ] **Horaires d'ouverture:**
  - [ ] Jours de la semaine
  - [ ] Heures d'ouverture (ex: Lun-Ven: 8h-16h)
  - [ ] Jours fériés (si applicable)
